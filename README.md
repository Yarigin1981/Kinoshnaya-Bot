# Киношная Telegram Bot

Бот для автоматического постинга в канал [@kinoshnaya3000](https://t.me/kinoshnaya3000) с AI-генерацией контента.

## Возможности

- 🤖 Генерация постов через Claude API
- ⏰ Автопостинг по расписанию (10:00 и 19:00 MSK)
- 📊 Управление очередью постов
- 💬 Команды управления через Telegram

## Быстрый старт

### 1. Установка

```bash
cd apps/telegram-bot
npm install
```

### 2. Настройка .env

```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_CHANNEL_ID=@kinoshnaya3000
ANTHROPIC_API_KEY=ваш_ключ_claude
ADMIN_USER_ID=ваш_telegram_id
```

### 3. Генерация постов на неделю

```bash
npm run generate
```

### 4. Запуск бота

```bash
npm run dev   # режим разработки
npm start     # продакшен
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/status` | Статус очереди постов |
| `/next` | Превью следующего поста |
| `/publish` | Опубликовать сейчас (только админ) |
| `/list` | Список постов в очереди |

## Скрипты

| Скрипт | Описание |
|--------|----------|
| `npm run generate` | Сгенерировать посты на неделю |
| `npm run post:now` | Опубликовать следующий пост |
| `npm run dev` | Запуск в режиме разработки |
| `npm start` | Запуск в продакшене |

## Структура проекта

```
src/
├── index.ts              # Главный файл бота
├── config.ts             # Конфигурация
├── services/
│   ├── telegram.ts       # Telegram API
│   ├── claude.ts         # Claude API для генерации
│   └── scheduler.ts      # Расписание публикаций
├── data/
│   ├── posts-store.ts    # Хранилище постов
│   └── posts.json        # Файл с постами
└── scripts/
    ├── generate-posts.ts # Генерация постов
    └── post-now.ts       # Ручная публикация
```

## Workflow

```
1. Запускаешь npm run generate
   → Claude генерирует 7 постов на неделю
   → Посты сохраняются в очередь

2. Запускаешь npm run dev
   → Бот публикует посты в 10:00 и 19:00 MSK
   → Можно управлять через команды

3. Каждую неделю повторяешь npm run generate
```
